Why it feels useful immediately

Built for the moment when copy-paste becomes a workflow.

Instead of sending temporary text through chat, email, or ad-hoc notes, OurBin keeps the flow local, searchable, disposable, and still structured enough to scale from quick snippets to day-long coordination.

Low friction from the first paste

Import directly from the clipboard, create bins in one action, and choose expiration from a minute-level utility bin to a persistent reference bin.

  • Clipboard import and direct typing
  • Flexible expiration from minutes to permanent
  • One-page creation flow with instant listing

Shareable across your LAN, grounded in local control

Each item gets a UUID, so it can be reopened or edited from another device on the same network without adding accounts, sync layers, or heavy dependencies.

  • UUID access for view and edit flows
  • Raw text endpoint for direct retrieval
  • FastAPI health checks and generated documentation
Highlighted features

Workflow and architecture

Simple on the surface, well-shaped underneath.

OurBin keeps the frontend light while the backend handles storage, expiration, renewal, raw text delivery, and operational maintenance through a compact API surface.

01

Paste or type once

Capture plain text quickly, optionally import from clipboard, and assign the right lifetime.

02

Get a durable handle

Each bin receives a UUID, making it easy to revisit, edit, share, or fetch as raw text later.

03

Manage at list scale

Sort by creation or expiration, batch renew selected bins, soft delete them, or clean expired ones.

04

Deploy without ceremony

Run it locally with Python or ship it with Docker Compose while keeping data in SQLite.

Under the hood

FastAPI + SQLite + Docker + zero-build frontend.

The stack stays approachable but production-friendly enough for internal use. No framework lock-in, no client build step, and no unnecessary ceremony for a tool that should just work.

  • Python 3.11+, FastAPI, SQLite
  • REST API with health endpoint and generated docs
  • Docker Compose deployment with persistent data volume
  • Vanilla frontend that remains easy to audit and modify
